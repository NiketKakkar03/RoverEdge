# Issue tracker: GitHub

Issues and specs live in NiketKakkar03/RoverEdge.
Use the gh CLI with --repo NiketKakkar03/RoverEdge.

- Read and search existing issues before creating duplicates.
- Publish specifications as issues with the configured triage label.
- For multiline content, use --body-file with a saved Markdown file.
- Use native sub-issues and blocking dependencies when supported; otherwise record parent and blocker links in issue bodies.
- Leave issues unassigned unless the user requests an assignment.
- Do not add Codex labels, mentions, assignments, or automation.
- A triage label describes readiness; it does not authorize execution.
- Comment with the outcome before closing a resolved issue.

PRs as a request surface: no.
