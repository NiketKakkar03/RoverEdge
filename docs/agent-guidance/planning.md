# Planning and ambiguity

- Before implementation, state assumptions that affect the proposed behavior or approach.
- When multiple interpretations would materially change the result, present the alternatives and ask which is intended before doing dependent work.
- Use judgment for routine choices within the agreed scope; trivial tasks do not require a formal plan.
- If a simpler approach satisfies the request, explain the trade-off before committing to a more complex approach.
- For multi-step work, give a brief plan pairing each step with its verification check. Use [verification](verification.md) to define completion.
